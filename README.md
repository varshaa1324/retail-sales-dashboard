# Retail Sales Dashboard

## About
Analyzed 10,000+ retail transactions to find sales and profit insights using Python and Tableau.

## Tools Used
- Python
- Pandas
- Jupyter Notebook
- Tableau

## Steps
1. Downloaded dataset from Kaggle
2. Cleaned data using Pandas
3. Performed EDA to find insights
4. Built interactive Tableau dashboard

## Key Findings
- Technology category has highest sales
- California is the top performing state
- Overall Profit Margin is 12.47%
